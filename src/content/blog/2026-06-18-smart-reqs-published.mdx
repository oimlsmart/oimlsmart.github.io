> **Editor's note, September 2026.** The SMART_REQS set is superseded: it described the platform's first, YAML-based design, and the current design authors every normative model as a Primmel package. The documents remain in the platform repository as the historical record; see [The SMART_REQS set](/docs/specifications).

The 11-document **SMART_REQS** specification set is now available on this
site in draft form. Each document defines one aspect of the SMART platform:

1. System Architecture
2. Requirement & Conformance Model
3. Form & Measurement Model
4. OCL Expression Language
5. Evaluation & Condition Model
6. YAML Schema Specification
7. Calculation Primitive
8. Expression Language (AsciiMath + OCL)
9. Table Primitive
10. Certification Workflow Model
11. Variable & Symbol Model

## How to read them

If you're new to the formal specs:

1. Read **01 (System Architecture)** for the overview.
2. Read **02 (Requirement & Conformance Model)** for the core entity types.
3. Skim **06 (YAML Schema)** and **07–09 (Calculation, Expressions, Table primitives)** for the declaration language.
4. Read **10 (Certification Workflow)** if you're integrating with OIML-CS.

For the narrative version, see the [Developer Guides](https://www.oimlsmart.org/studio/docs/guides/getting-started).
