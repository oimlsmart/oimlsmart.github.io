The SMART_REQS set is the founding specification of the SMART platform: eleven documents, announced in June 2026, which defined the system architecture, the requirement and conformance model, the form and measurement model, the expression language, the evaluation and condition model, the YAML schema, the calculation and table primitives, the certification workflow model, and the variable and symbol model.

**The set is superseded.** The documents describe the platform's first design, in which the model content of a Recommendation was declared in YAML files. In the current design every normative model is authored as a Primmel package, and the pinned package set is the single source of truth from which the platform derives every surface. The modelling language is defined by the [Primmel language specification](https://www.primmel.org), and the current platform documentation lives in [the docs collection](/docs/).

The eleven documents remain in the platform repository as the historical record of the design's evolution, each carrying the supersession notice at its head. The [publication announcement](/news/2026-06-18-smart-reqs-published) records what the set specified at the time.
